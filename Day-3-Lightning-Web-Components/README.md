## README Questions

### 1. What is LWC?

Lightning Web Components (LWC) is Salesforce's modern UI framework used to build fast, reusable, and interactive user interfaces. It is based on standard web technologies such as HTML, JavaScript, and CSS.

### 2. What did you build?

I built a Lightning Web Component named **placementHome** for a Placement Management System. The component displays:
- Welcome to Vishnu Placement Portal
- Student information
- Today's Date
- Number of Companies
- Number of Jobs
- Applications Submitted
- Welcome Message button
- Application Status button using JavaScript

### 3. Which file contains HTML?

The **placementHome.html** file contains the HTML code that defines the user interface and page layout.

### 4. Which file contains JavaScript?

The **placementHome.js** file contains the JavaScript code used for variables, data binding, and button click events.

### 5. What did you learn today?

Today, I learned:
- Introduction to Lightning Web Components (LWC)
- LWC file structure
- Creating and deploying an LWC
- Data Binding
- JavaScript variables and Button click events
- Deploying components using Lightning App Builder
- Building a simple Placement Management System dashboard
